# Cookbook Learning Delivery

Read ../../../docs/learning-contract.md and the app's brief and verified implementation. Map each learning outcome to one roadmap lesson, a codelab action, a source checkpoint, and an observable result. Explain decisions rather than copying entire source files into prose. Pin the codelab to reproducible source, include likely setup failures, and end with an independent challenge with acceptance criteria. Verify links and run the documented steps from the stated starting point. Keep missing academy lessons marked planned and distinguish app verification from completed teaching material. Never invent screenshots, passing tests, or learner-review evidence.
