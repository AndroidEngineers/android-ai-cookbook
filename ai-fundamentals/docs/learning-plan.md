# PocketCards learning plan

Status: app implementation in progress; this is the mapping for the existing academy roadmap. Website lessons have not been rewritten or published as part of this app build.

| Existing Fundamentals module | PocketCards implementation | Hands-on milestone |
| --- | --- | --- |
| What AI means in an Android app | Hand-authored sample versus Firebase generation | Explain the difference before making a request |
| Tokens, context and model behavior | Prompt and 8,000-character input bound | Compare short and information-poor notes |
| Choosing cloud, on-device or hybrid | Firebase inference and local-only deck storage | Trace which data leaves the device |
| Kotlin architecture for model calls | ViewModel, repository, generator interfaces | Follow one action from Compose to data |
| Evaluation, privacy and cost basics | Review-before-save, validation, cancellation | Score factual support against source notes |
| Connecting the first AI feature | Create → edit → save → study | Complete the full flow |
| Capstone and portfolio review | Independent topic organization extension | Explain and test the added feature |

The [local walkthrough](codelab.md) documents the current project. A separate runnable starter, immutable instructional checkpoints, and the dedicated website codelab remain release work. This build must not be labeled a completed course or learning journey.
