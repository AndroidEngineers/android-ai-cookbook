# Troubleshooting

- **No Gradle wrapper at the root:** expected during the foundation stage. There is no runnable Android sample yet. Follow a recipe's status and source path.
- **Catalog validation fails:** the error identifies the entry/field. Check relative paths, unique IDs, required publication evidence, and valid academy links.
- **A recipe is marked draft:** its acceptance criteria describe future work, not a working implementation. Use its linked academy lesson for current learning material.
- **An academy link fails:** report the exact URL using the documentation issue form.

When samples are added, each recipe must explain at least its likely environment, authentication, device/model availability, and runtime failures. Include versions and the first meaningful error in reports; redact credentials and private data.
