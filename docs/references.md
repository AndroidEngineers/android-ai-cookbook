# Official references

Use these as primary references when implementing recipes. Check current versions and availability at implementation time; this index is not a compatibility claim.

- [Android AI](https://developer.android.com/ai) — Android platform and AI integration guidance.
- [Android AI samples](https://github.com/android/ai-samples) — official sample implementations; preserve their licenses when reusing code.
- [Gemini cookbook](https://github.com/google-gemini/cookbook) — provider examples and patterns.
- [Firebase AI Logic](https://firebase.google.com/docs/ai-logic) — supported client integrations and configuration.
- [ADK on Android](https://developer.android.com/ai/adk) — Android-specific agent development guidance.
- [ML Kit GenAI](https://developers.google.com/ml-kit/genai) — capability and model requirements.
- [AppFunctions](https://developer.android.com/ai/appfunctions) — Android capability interfaces and availability notes.
- [Model Context Protocol](https://modelcontextprotocol.io/docs/getting-started/intro) — protocol concepts and architecture.

References are credited inspiration; no sample code has been copied into this scaffold.
