# Getting started

The repository currently contains plans and authoring tools. There is no root Android application or Gradle build yet.

## If you want to learn today

Open a planned recipe and follow its academy lesson link. For a wider introduction, use [Android + AI fundamentals](https://www.androidengineers.in/roadmap/ai-android-fundamentals?utm_source=github&utm_medium=repository&utm_campaign=android_ai_cookbook&utm_content=getting_started).

## If you want to contribute

Install Python 3.11+, clone this repository, and run `python3 scripts/validate_catalog.py`. Pick a draft and read its acceptance criteria before adding code. The [contribution guide](../CONTRIBUTING.md) explains how to turn it into a tested recipe.

Future samples will document their own Android Studio, JDK, Gradle, Kotlin, SDK, and model requirements. Do not assume one toolchain or physical device works for every AI API.
