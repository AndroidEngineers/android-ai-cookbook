# App brief template

Copy to `<topic>/docs/app-brief.md` when starting that topic.

- Topic and working title (brand name may remain undecided)
- User problem and primary audience
- One core interaction worth demonstrating
- Three to five MVP features; explicit later features
- Learner prerequisites and observable learning outcomes
- App runtime, optional server, inference location, and credential boundary
- Devices/accounts/models needed to verify the implementation
- UI states, persistence, navigation, and failure/recovery behavior
- Architecture decisions and relevant official/local skills
- Roadmap lessons → codelab steps → source checkpoints
- Behavioral acceptance criteria and quality evaluation cases
- Completion evidence and remaining limitations

Start with a narrow vertical slice; choose the toolchain against current official documentation when implementation begins.
